# Favorite Module

The `Favorite` module handles the display of games that the user has marked as favorites.

## 📋 Requirements

- iOS 15.0+
- Swift 5.0+

## 🛠 Features

- **Favorite List**: Displays locally saved favorite games using Realm.
- **VIPER Architecture**: Implements View, Interactor, Presenter, Entity, and Router.

## 📦 Dependencies

- **Core**: Realm database access.
- **Components**: UI components.
- **GameDetail**: Navigation to detail view.

## 📦 Installation

This module is available via Swift Package Manager.

```swift
.package(url: "https://github.com/adedwi1808/game-catalogue-Favorite-package.git", from: "1.0.3")
```
